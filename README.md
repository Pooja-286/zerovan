# ZEROVAN

ZEROVAN is a sustainable-choice ecosystem that helps users understand
what they have, what they can do with it, and what sustainable choice
they can make next.

## Core Flow

Input → AI Understanding → Recommendation → Partner Matching
→ Action → Impact → Reward

## Project Structure

- frontend/ - Web application
- backend/ - Backend API and database
- ai/ - AI, ML, NLP and recommendation system
- data/ - Dataset and sample data
- docs/ - Project documentation
